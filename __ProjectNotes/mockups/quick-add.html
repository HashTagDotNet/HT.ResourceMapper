What Changed vs Today — replaces ResourceEditor.razor Create mode (GeneralTab → TagsTab → DependencyTab ×2 → ReviewTab, five tabs, Tier first, Key + Identity rows, primary-link radio column, nested "Create new…" that navigates away via EditorNavStack). One form in the order a person thinks: Name → Type → Azure Resource Id(s) → Key Tags → Depends On → Save. Tier defaults to the configured default domain and Key auto-fills from Name; both move under More Options with Description, the remaining type-template tags, the primary link choice and the Dependent On list. The dependency picker's "Create new…" opens this same form as a dialog instead of leaving the page. The uniqueness check still runs server-side as you type (Resource_CheckUnique).
