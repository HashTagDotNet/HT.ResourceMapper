Read this as the answer to "did the MudBlazor decision change anything?" — it did not change the design. 13 of 14 pieces are layer 1 or 2, i.e. supported MudBlazor APIs plus CSS that never touches Mud's internals. The single red row is the one thing I refuse to guess at: I'll measure the real dense floor before deciding whether to accept ~36px or override.

Still a caveat: this is hand-drawn HTML, not MudBlazor. It cannot tell you what Mud actually renders. The only honest fix is a throwaway page built with real components — say the word and I'll build and screenshot one before any production code is touched.
